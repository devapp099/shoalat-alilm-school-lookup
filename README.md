# موقع الاستعلام عن بيانات الطلبة — مدرسة شعلة العلم

نظام بسيط للاستعلام عن الصف والشعبة بالاسم الثلاثي أو الكامل، مع دعم كتابة الاسم بالصوت.
مبني بـ HTML وCSS وJavaScript فقط، ويعمل مباشرة على GitHub Pages.

## الملفات

- `index.html` — هيكل الصفحة
- `style.css` — تصميم عربي متجاوب مستوحى من ألوان الشعار
- `script.js` — منطق البحث والتحقق والرسائل
- `data.js` — بصمات مشفرة لصيغ الأسماء الثلاثية والكاملة، دون أسماء مكشوفة
- `images/school-logo.jpeg` — شعار المدرسة

## رفع المشروع إلى GitHub

```bash
cd shoalat-alilm-school-lookup
git init
git add .
git commit -m "الإصدار الأول: نظام الاستعلام عن بيانات الطلبة"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/shoalat-alilm-school-lookup.git
git push -u origin main
```

## النشر

**GitHub Pages:**
Settings → Pages → Branch: `main` → Folder: `/root` → Save.
سيصبح الموقع متاحًا على: `https://<اسم-حسابك>.github.io/shoalat-alilm-school-lookup/`

**Render (Static Site):**
1. New → Static Site → اختر مستودع المشروع الجديد
2. Build Command: اتركه فارغًا
3. Publish Directory: `.`

## ملاحظات هامة قبل الاستخدام الفعلي

- يتضمن الإصدار 438 طالبًا وطالبة: الأول 106، الثاني 104، الثالث 113، والرابع 115.
- لا يحتوي `data.js` على الأسماء؛ بل على بصمات SHA-256 لصيغ البحث.
- الملفان `ثاني -2.pdf` و`ثاني -2-1.pdf` متطابقان، لذلك أُدرجت الشعبة مرة واحدة.
- يقبل النظام ثلاثة أجزاء من الاسم أو الاسم الكامل مع المحافظة على ترتيبها، ويمكن حذف «بن/بنت».
- عند تطابق الاسم المختصر مع أكثر من طالب، يطلب النظام إضافة جزء آخر من الاسم.
- يعمل الإدخال الصوتي في المتصفحات التي تدعم Web Speech API، وقد يطلب المتصفح السماح باستخدام الميكروفون.
- البحث بالاسم وحده في موقع عام أقل حماية من نظام يعتمد على رقم تحقق إضافي.
- لا ترفع ملفات PDF الأصلية أو ملف الاستخراج الداخلي إلى المستودع العام.
- الحماية الأقوى مستقبلًا تكون باستخدام خادم وقاعدة بيانات خاصة بدل الاستضافة الثابتة.
- تم ضبط حد أقصى للمحاولات المتتالية (20 محاولة) مع قفل مؤقت 10 ثوانٍ.
